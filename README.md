# Open ERC Composition Laboratory (OECL)

An open research infrastructure for studying deterministic protocol composition through reproducible experiments.

## Mission

OECL provides an open framework for evaluating protocol compositions using reproducible experiments, quantitative metrics and public datasets.

The laboratory investigates protocol composition rather than individual protocols.

## Principles

- Open Specifications
- Open Source
- Reproducible Experiments
- Protocol Neutrality
- Evidence Before Conclusions
