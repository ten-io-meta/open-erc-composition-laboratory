# Case Study 001 — ERC-8060 Reservable

This case study evaluates ERC-8060 Reservable as the first protocol-specific integration inside the Open ERC Composition Laboratory.

## Purpose

The objective is to validate whether the OECL pipeline can resolve a required capability, load a protocol manifest, instantiate the corresponding adapter, execute validation rules, and publish reproducible outputs.

## Capabilities

- Reservation
- Accounting

## Current Validation

- reservation-safety
- authority-safety

## Status

Experimental.
