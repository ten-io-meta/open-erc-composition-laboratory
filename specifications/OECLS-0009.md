# OECLS-0009

# Dataset Specification

Status: Draft

Version: 0.1

---

# Title

Dataset Specification

---

# Purpose

This specification defines how experimental data is stored, versioned, published and reused within the Open ERC Composition Laboratory (OECLS).

Datasets provide the permanent evidence generated by protocol composition experiments.

---

# Principles

Datasets shall be:

- open
- reproducible
- immutable
- versioned
- machine readable

---

# Dataset Structure

Every dataset contains:

- metadata
- experiment information
- benchmark configuration
- protocol composition
- execution results
- collected metrics

---

# Metadata

Every dataset records:

- dataset id
- creation date
- experiment id
- benchmark id
- author
- repository commit
- protocol versions
- OECLS version

---

# Raw Data

Raw execution data should be preserved whenever possible.

Examples:

- execution logs
- event traces
- invariant evaluations
- benchmark outputs

Raw observations are never modified.

---

# Derived Data

Derived data may include:

- aggregated metrics
- statistical summaries
- comparisons
- visualizations

Derived data must reference its source dataset.

---

# Formats

Recommended formats include:

- JSON
- CSV
- Markdown
- HTML

Additional formats may be supported.

---

# Dataset Versioning

Datasets are immutable.

Corrections generate new dataset versions.

Previous versions remain accessible.

---

# Public Availability

Datasets should be publicly available whenever possible.

Researchers should be able to independently reproduce published observations.

---

# Future Extensions

Future dataset specifications may include:

- distributed storage
- IPFS publication
- cryptographic verification
- signed datasets
- DOI assignment

---

# Summary

The Dataset Specification defines how experimental evidence is preserved, shared and reused throughout the Open ERC Composition Laboratory.
